# Problem 2: Fancy Form

A responsive currency swap form built with React and Vite. Prices come from the challenge's [price feed](https://interview.switcheo.com/prices.json), and token artwork comes from [Switcheo token icons](https://github.com/Switcheo/token-icons).

## Run locally

```sh
cd src/problem2
yarn dev
```

## Checks

```sh
yarn lint
yarn build
```
